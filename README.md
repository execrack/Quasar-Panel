# Quasar RAT

## Overview

Quasar RAT is an open-source, Windows-based remote administration tool written in C# and built on the .NET ecosystem. It has been used for legitimate remote administration and technical research, but has also been abused as a Remote Access Trojan (RAT) in cyberattacks.

## Technical Overview

- **Programming Language:** C#
- **Platform:** Microsoft Windows
- **Framework:** .NET
- **Architecture:** Client-server
- **Communication:** TCP-based network communication

## Security Considerations

Quasar RAT has been associated with security incidents involving unauthorized remote access, credential theft, keylogging, file manipulation, and remote command execution.

Its public source code has also enabled modified variants to be used in malicious campaigns.

## Purpose

This repository documents Quasar RAT from a software and cybersecurity perspective, including its architecture, technical background, and security implications.

Any analysis or testing should be conducted only in an isolated environment on systems for which explicit authorization has been granted.
